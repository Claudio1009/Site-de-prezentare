## Overview

A lightweight static portfolio website introducing a developer profile, selected projects and contact links. The Romanian-language page demonstrates fundamental web layout, semantic sections and custom CSS styling without a backend or build pipeline.

## Features

- Personal profile and introduction.
- Project presentation section.
- Contact and external profile links.
- Locally stored image assets.
- Custom stylesheet.

## Structure

```text
Site-de-prezentare/
├── index.html
├── style.css
├── images/
└── README.md
```

## Run locally

```bash
git clone https://github.com/Claudio1009/Site-de-prezentare.git
cd Site-de-prezentare
```

Open index.html in a browser. Alternatively, serve the repository with a static HTTP server. No package installation or database is required.
